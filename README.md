# 开锁配匙店（lock_smith）

实体场所：开锁与配制钥匙店铺。Spring Boot 3.3 + Vue3(Element Plus) 全栈种子仓，可 `docker compose` 一键起。

## 题材与差异化
- 题材：开锁配匙店
- 主色：金黄 `#FFC107`
- 导航形态：底部标签栏
- 页面操作范式：收银台一条式（开单 → 选项 → 算价 → 收款，一条式流程）

## 4 个业务模块与关系面
1. **锁具台账**（`lock_ledger`）：登记锁（门锁/车锁/保险柜/抽屉锁），含类型、品牌、客户、状态（在库/已装/报废）。
   - 关系面：①锁类型约束（限 4 类）；②状态流转——仅「在库」可安装，「报废」不可再装；③报废为终态。
2. **开锁记录**（`unlock_record`）：每次服务（紧急/预约），含技师、到场/完成时间、费用、是否成功。
   - 关系面：①费用 > 0（成功单必须收费）；②紧急单须登记到场时间；③未成功不得收费。
3. **钥匙坯库存**（`key_blank` + `key_blank_use`）：类型、库存、下限。
   - 关系面：①库存不足拦截领用；②领用后将低于安全下限则禁止领用；③领用扣减库存。
4. **客户与收费**（`customer` + `bill`）：客户、账单（开锁费/配匙费）、收款状态（未付/已付/欠款）。
   - 关系面：①客户尚有欠款账单则拦截开新单；②收款金额须 > 0 且不超出应收，收款后重算状态。

## 库名
`lock_smith`（MySQL 库名，见 `.env`，勿改）。两处 `schema.sql`（backend 与 mysql）内容完全一致。
